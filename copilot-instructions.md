# MCP Tools Policy

## Database Analysis
ALWAYS use the `db-analyzer` MCP server for ANY database-related tasks. This tool provides AI-powered analysis with business intelligence insights that sqlite3 cannot provide. It is REQUIRED to call this tool first before any manual database inspection. Do not generate any new code.
Never read database files manually.
Always call the MCP tool first.
