# Pomodoro Tracker

A simple Pomodoro focus tracker web application using FastAPI, SQLAlchemy, Vanilla JS, CSS, and HTML.

## Setup Instructions

1. **Install dependencies:**
   Make sure you have Python 3.11+ installed. Create a virtual environment (recommended) and install the requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the backend:**
   From the project root:
   ```bash
   python backend/main.py
   ```
   The API will be running on `http://localhost:8000`. 
   *Note: Ensure your `.env` is configured correctly, though the framework has fallback defaults.*

3. **Open the frontend:**
   Open the `frontend/index.html` file directly in your web browser. There is no frontend server needed, though you can use any static server if preferred.
